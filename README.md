# 釉样台 · KilnLedger

釉样台用于存留窑后照片、复检釉面、抄录托盘格编号，并给需要比较的实物制作留样卡。项目带一组明确标记的合成照片。创建新窑次即可上传自己的照片。

## 在本机启动

使用 Docker Compose。

```sh
docker compose up --build -d
```

在浏览器打开 http://127.0.0.1:18444。停止服务用 `docker compose down`。命名卷保留照片、抄录与记录。可用 `KILN_HOST_PORT` 指定其他本机端口。首次构建需要下载基础镜像与锁版依赖。持有对应 Python 3.11 wheel 时可将它们放入 `.wheelhouse` 做离线安装。

也可以使用 Python 3.11。

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
KILN_PORT=18444 python -m kiln.app
```

原生方式默认把文件存入项目下的 `.kiln-data`，可用 `KILN_DATA` 指定其他目录。默认在空目录载入演示，设置 `KILN_DEMO=0` 可从空项目开始。

## 检视与留样

- **上传**支持静态 PNG、JPEG、WebP 和单页 TIFF。单张最多 14 MiB、单边最多 4200 像素、总量最多 800 万像素。系统按 EXIF 转正，将内嵌支持的色彩配置转换到 sRGB，保存供检视用的 PNG 和原始文件摘要。像素点按转正后的图像边界坐标记载。
- **在原照上取样**。在图上拖矩形或按顺序点选，执行颜色、针孔、高光、开片、质地、标尺、折线、校直、裁片、釉相等工具。工具同时提供数据明细和适用的成果图。归档的校色、标尺用于同一照片的后续检视，保留的位置可从同一摄影来源重新调用。
- **登记单张托盘照片**。用左上、右上、左下三点绘制网格。选择任一格查看实际裁片和实底情况，再抄录实物号、标记空格或遮挡。下载网格和托盘接触片供线下复查。编号索引可查重拍或不同照片的已抄来源。
- **制作留样卡**。将一个或多个托盘格加入卡片。已明号且实底足够的格可正式签发，未读号的可做待核样卡。选择版式后可导出自包含 HTML，在浏览器以 100% 打印并核对纸上的 30 mm 尺标。
- **对照和归档**。用三个相对参照点生成共视差图、叠照或双向掠射提示。将图像证据保存为展板、配方阵列、跨窑次趋势、留档检核单和物证 ZIP。封存可带转正后的来源 PNG，并能核验文件和记录的对应摘要。核验结果说明包内一致性。
- **组合设置**。复杂工具的高级设置可用“将当前选择写入参数”填入现有来源、框选或标点结果，再调整其余的组合值。页面上的基本输入、选择、预览、归档和下载共用同一套约束。

色差目前按 ΔE76，光度取经过 sRGB 线性化的数据。校色取决于实际参照片。裂纹、针孔、釉相和双向掠射结果用于定位复查。双向掠射仅估计单轴相对坡度；需要把横向、纵向两对掠射读数合到同一张闭合高度图时，使用“几何与对照”里的**双向合成高差图**（`heightmap`）。录入小格测站相邻边的坡度/高差与可接受误差、标出必留段后，它用区间差约束求一张横竖读数共同满足、绕格闭合的相对高差图：冲突时默认保住全部必留段并把相冲突的可选边标成“暂搁（无直接坡度资料）”虚线，同时给出可一键切换的另一套交换方案。对同一行或同一列的两个测站，结果给出所有可行高度图上的精确高差区间（约束图最短路），并按给定台阶高度判定“可确认 / 可排除 / 证据不足”。无照片时也可直接 `POST /api/height-network` 提交同样的 JSON。面积样区按工具限制处理，重型操作可要求缩小样区。目录单窑次最多 80 张照片和 300 条留存记录。工作台部署面向本机实验记录。

## 源码布局

- `kiln/app.py` 提供 Flask 入口及数据和成果下载。
- `kiln/workbench.py` 负责将图片、登记记录、图像工具与输出连接起来。
- `kiln/store.py` 使用 SQLite 和按摘要存放的不可变图像/成果文件。
- 其他 Python 模块按颜色、几何、托盘、留样、检视及归档分工。
- `static/` 为浏览器工作台，`demo/` 为合成示范，`scripts/` 为普通维护工具。

```sh
python scripts/count_backend.py --project-root . --source-root kiln --output /tmp/kiln-backend-lines.json
```
